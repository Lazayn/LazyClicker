# LazyClicker

有bug或者什么想要的去issue或者私信或者评论区

## Info

- ai code

- 还可以的安卓autoclicker，输出的是左键，以及非常牛逼的cursor track

- 建议系统版本: android 12

- 最低系统版本: android 10 (能使用shizuku的最低版本,也就是无线调试功能刚出的版本)

- 有些设备可能在游戏里会识别成触屏(万一是版本问题呢xd)


## How to Use

进游戏转动视角，找到能触发click的角度，然后鼠标不能动，应用开悬浮窗，用手点左上角设置，把虚拟光标灵敏度调为0×

不会问我

## Notes

* 有一些幽灵调节选项，之后会移出
* 补点太高会卡
* 开挂违法。
